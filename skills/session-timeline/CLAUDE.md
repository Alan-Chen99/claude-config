# session-timeline/

Focus-directed extraction of opencode session content into raw evidence
artifacts. Separates the evidence layer (what's in the log) from the
interpretive layer (what it means) so rounds can build on stable substrate
without re-mining.

## Files

| File       | What                                          | When to read              |
| ---------- | --------------------------------------------- | ------------------------- |
| `SKILL.md` | Skill definition and workflow                 | Using or invoking this skill |
