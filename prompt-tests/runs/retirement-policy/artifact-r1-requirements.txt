# Pillow is pinned, but NOT for the reason the pin is usually explained.
#
# The record says: 10.3.0 made md thumbnails visibly softer because 10.3
# changed the default resample filter of Image.thumbnail(), which render.py
# did not pass. Tested directly, that mechanism does not hold:
#   - thumbnail()'s default is Resampling.BICUBIC in both 10.2.0 and 10.3.0
#   - the 10.3.0 changelog contains no resampling, resize, thumbnail or
#     draft() change
#   - output is byte-identical between the two versions across 78 cases --
#     13 source dimensions straddling every draft() scale boundary, JPEG and
#     PNG sources, sm/md/lg, through the quality=88 encode
#
# render.py now names its resample filter, so the reported mechanism can no
# longer occur whatever version is installed. The softness customers actually
# saw in February remains unexplained, so the pin stays until someone knows
# what it was. Before bumping, render a real customer image at md under both
# versions and compare, rather than trusting either this note or the record.
