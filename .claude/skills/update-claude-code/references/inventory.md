# Coupling inventory

Every place this repo reads a Claude Code data shape, env var, hook field, settings key, tool
name, record type or source line, and how it fails when a release moves it. Before editing a
file, grep here for its path and the cc names it touches; at an upgrade (runbook step 13),
re-verify every row against the new tree: a fixed-string grep for its literal under
`/repos/claude-code-decompiled/src` finds the code, and only reading it there re-verifies the
claim: a marker can survive a stale regex beside it. Source claims are read off 2.1.310 except those `still-to-check.md` lists; a measurement carries its date.

## Mirrors of cc's own algorithms

Re-read each against the source every release; a test cannot tell a mirror that drifted from
one that never matched. In `src/claude_config/env_context/`: `environment.py`'s
`resolve_shell` (`is not a valid bash/zsh path, falling back to detection`), `_executable` (the
`"--version"` fallback under `timeout: 1000` that lets a bare `CLAUDE_CODE_SHELL=bash` resolve),
`worktree_common_dir` (`"commondir"` beside `"worktrees"`) and `git_snapshot`
(`This is the git status at the start of the conversation`; cc's copy is a `session_context`
attachment, never part of `# Environment`); `scratchpad.py`'s path algorithm (`"scratchpad"`;
past the 200-character slug cc appends a hash and this module raises); `drift.py`'s anchor,
window and timeout constants, tuned to the binary layout — its docstring carries the
partial-window measurement, and cc's env-block builder (`Scratchpad directory:`) is re-read
against `render.py`.

## Unset knobs

Nothing sets these; each would silently change a row above.

- `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`: one model for every subagent, voiding every `model:` in `agents/*.md`.
- `CLAUDE_CODE_ENABLE_TODO_TOOLS`: restores `TodoWrite` and `TaskCreate`/`Get`/`Update`/`List`.
- `CLAUDE_CODE_DISABLE_1M_CONTEXT`: the launchers' `[1m]` stops meaning 1,000,000 (`zai.sh` falls to 200,000) and the 1M beta header goes.
- `CLAUDE_CODE_ARTIFACT_TOOLSET`: `1` splits Artifact into a shorter tool plus deferred `ArtifactComments`/`ArtifactData`/`ArtifactCheck`, `0` forces the unified tool, unset defers to `tengu_cobalt_plinth_damson`. Inert while `enableArtifact` is off.
- `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP`: removes the memory-pressure reaper of an interactive session's idle background shells (`notes/print-mode-task-lifetime.md`).
- `CLAUDE_CODE_AUTO_BACKGROUND_TIMEOUT_MS`: lowers a main-agent Bash `timeout` to `max(value, 2000)`, shortening `--wait` without `BASH_MAX_TIMEOUT_MS`.
- `CLAUDE_CODE_HANDBACK_PROVENANCE`, `CLAUDE_CODE_SENDMESSAGE_HANDBACK` (else `tengu_melodic_wolf`, `tengu_lively_waffle`): the first removes the `[Subagent hand-back]` frame `cc_pretty` renders; the second stops auto mode delivering the report as a message.
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`: stops the changelog fetch (step 4), update check, `models.list`, catalog refresh, and closes the claude.ai sync gate.
