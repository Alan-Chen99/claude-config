# Coupling inventory

Every place this repo reads a Claude Code data shape, env var, hook field, settings key, tool
name, record type or source line, and how it fails when a release moves it. Source claims are
read off 2.1.310 except those `still-to-check.md` lists; a measurement carries its date. Where a
row sends you to a code comment, that comment holds the claim step 13 re-verifies.
