Write a Python function `slugify(text)` that converts a string into a URL slug:

- Lowercase ASCII letters and digits stay as-is.
- All other characters are replaced with a single hyphen.
- Collapse consecutive hyphens into one.
- Strip leading and trailing hyphens.

Examples: `slugify("Hello, World!")` -> `"hello-world"`, `slugify("  --foo__bar--  ")` -> `"foo-bar"`.

Save it as `slugify.py` in the current directory.
