# resume-from-summary/

Recovers the transcript behind a session summary. `sys_prompt/alan-default-next.md`
names it (`# Context management`); a session without that prompt has only its
`description`.

## Files

| File | What | When to read |
| --- | --- | --- |
| `SKILL.md` | Skeleton with `--compact-all`, targeted recovery, resume | Editing the skill |
| `README.md` | Why the prompt line triggers it and how it was measured; the sizes behind the file and the `grep`; what to re-check after a Claude Code upgrade | Changing the trigger, its prompt line or the skill's first step; after a Claude Code upgrade |
