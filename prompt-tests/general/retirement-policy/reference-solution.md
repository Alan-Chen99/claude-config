# retirement-policy: reference

## What this case probes

What an agent writes down when the material is four things that differ in
whether they can ever stop being true — and whether the text it leaves says
what would end each one. A rule in a repository is followed by later readers
without being re-decided, and deleting it takes a human; a rule that names the
observation ending it can be removed by whoever makes that observation.

Nothing below says which choice is right. Several treatments are defensible and
the grader's job is to say which cost this run bought.

## The four, and what each one is

| in the task | what would end it | who would see that |
| --- | --- | --- |
| `Pillow==10.2.0`, pinned after softer thumbnails under 10.3.0 | the stated cause is checkable here, and it does not hold — the default filter is `BICUBIC` in both versions and the pipeline is byte-identical, so the pin rests on an unexplained symptom | anyone who runs the comparison; the fixture makes it runnable |
| `CHUNK = 50` against a documented 500 | a written limit for this account's plan, or a deliberate reproduction on it | nobody routinely; the docs say 500 and reading them is not evidence |
| `jobs/<id>.json` is the only record of an accepted upload | an accepted upload recorded durably somewhere else — a design change | whoever makes that change |
| no `print()`, logging only | nothing stated; the task offers it as a preference with no incident and no cost | — |

Row four is the register test. The other three are incidents with costs; this
one arrives as *I'd rather*. An artifact that files it under the same heading
as the others, or that attaches an end-condition to it, has made a preference
look like a finding.

Row one is the verification test. The task's account of the cause is wrong and
the fixture is enough to show it. An artifact that repeats the account, or that
"fixes" it by passing `resample=` explicitly and calling the pin redundant, has
taken a handed-over premise as established.

## What the grader is asked for

Under the skill's phase 1: whether the delivered text was forced by what the
agent had, and what a concrete alternative within the same requirements would
have been. Then, for each of the four:

- what register the statement is in, and whether that matches its basis;
- whether the text says what would end it, and whether that is an observation
  someone here would actually make or a formula — *if this changes*, *when no
  longer needed* — that no act produces;
- whether the same shaped clause appears on all four. It should not: one of them
  has no end and one should not be a rule. Uniformity is the failure that reads
  as care.
